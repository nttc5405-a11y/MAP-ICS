# 案件管制系統（第 1 階段：地圖核心）

指揮所版網頁：建案、底圖、劃區、標點、KML/KMZ/GPX 匯入匯出、事件日誌。
資料存在 Google 試算表與 Drive（GAS 模式），或先存在這台電腦的瀏覽器裡試用（本機試用模式）。

## 一、先在本機試用（不需要 Google）

1. 在這個資料夾開終端機，執行：
   ```
   python -m http.server 8080
   ```
2. 瀏覽器開 `http://127.0.0.1:8080/`
3. 頂列會顯示橘色「本機試用模式」。資料只存在這台電腦的瀏覽器，不會上傳。

> 不要直接雙擊 index.html 開（`file://` 會讓瀏覽器禁用儲存功能）。

## 二、部署 GAS 後端（約 10 分鐘，只做一次）

1. 到 Google 試算表新增一份空白試算表，命名「案件管制總表」。
2. 選單 **擴充功能 → Apps Script**，把 `gas/Code.gs` 全部內容貼進去（取代原本的 `myFunction`），存檔。
3. 上方函式下拉選 **setup**，按「執行」，依畫面授權（會顯示「Google 尚未驗證」→ 進階 → 前往）。
4. 看「執行記錄」，會有一行 **管理權杖（API_TOKEN）**，複製起來。忘了可執行 `showToken`。
5. **部署 → 新增部署作業 → 網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製 **網頁應用程式網址**（結尾是 `/exec`）。
6. 回到網頁，右上角 **設定**：貼上 GAS 網址與權杖 → 測試連線 → 儲存。頂列變綠色「GAS 連線模式」。

之後如果改了 `Code.gs`：**部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不變。

## 三、放上 GitHub Pages

把整個資料夾（`index.html`、`css/`、`js/`）推到 GitHub repo，Settings → Pages → 選 main 分支根目錄。
`gas/` 與 README 放不放都可以（`gas/Code.gs` 不含權杖，權杖只存在 Script Properties 與你的瀏覽器）。

## 第 2 階段：部署與派遣（已加入）

- **部署分頁**：單位（從名冊加入、點「上圖」放到地圖、可拖曳、設帶隊官與狀態）、人員（臨時人員確認／拒絕並編組、撤銷、代為加入）、案件 QR Code、名冊管理。
- **任務分頁**：派遣任務（指派單位或個人、目標區域、危險因子自動帶入）、六種狀態一鍵切換並記錄時間、代登回報。
- **升級既有 GAS**：把新的 `gas/Code.gs` 整份貼上覆蓋 → 部署 → 管理部署作業 → 編輯 → 新版本 → 部署。舊案件第一次開啟時會自動補建新工作表。
- **名冊**：第一次請到「部署 → 人員 → 名冊管理」貼上實際單位與人員（本機試用模式內建的是虛構範例）。

## 第 3 階段：手機現場版（`field.html`）

- **加入**：掃案件 QR → 選單位 → 選姓名（或輸入搜尋，「小明」可找到「王小明」）→ 確認。找不到就以臨時人員加入，等指揮所確認。手機會記住身分，下次一鍵加入。登入 24 小時後失效。
- **兩種檢視**（頂端切換，會記住上次選擇）：
  - 地圖：區域唯讀、我的任務所在區域加粗、顯示自己位置（不回傳）、點區域看危險因子與任務並可「在此回報」、底部抽屜有區域清單。
  - 清單：任務卡片（紅＝新任務、橘＝執行中、綠＝完成）、詳情含帶隊官與成員、時間軸、一鍵狀態（已接收／已抵達／執行中／完成／需支援）。
- **回報狀況**：文字＋最多 3 張照片（自動壓成長邊 1600px、約 300～500KB）＋位置（預設目前 GPS，可拖曳修正）。送出失敗會保留內容，按「重新送出」。
- **提醒**：畫面開著時約每 17 秒檢查一次，有新任務會震動（僅 Android）並顯示紅點。
- **指揮所端**：任務與回報清單可看照片（📷）、在地圖標出回報位置（📍橘點）。
- **權限**：手機只能看自己案件、改自己任務的狀態、新增回報，不能改區域。待確認的臨時人員只能看地圖與區域。
- **本機試用**：指揮所頁與手機頁共用同一個瀏覽器的資料，可在同一台電腦開兩個分頁模擬（QR 連結直接貼到新分頁）。
- 傷患回報屬於第 4 階段，尚未提供。

## 檔案說明

| 檔案 | 內容 |
|---|---|
| `index.html` | 指揮所版 |
| `css/style.css` | 樣式 |
| `js/config.js` | 底圖、案件類型、區域類別、危險因子快選（要改顏色／底圖網址改這裡） |
| `js/util.js` | TWD97 轉換、量測、節點簡化、對話框 |
| `js/api.js` | 資料層：本機試用模式＋GAS |
| `js/kml.js` | KML 匯出、KML/KMZ/GPX 匯入 |
| `js/map.js` | 地圖與繪圖 |
| `js/zones.js` | 區域清單與屬性 |
| `js/cases.js` | 案件列表與建案 |
| `js/app.js` | 狀態、同步、設定、工具 |
| `gas/Code.gs` | 後端 |

## 已知注意事項

- 魯地圖（`rudy.tile.basecamp.tw`）與 Happyman 航跡的圖磚網址是依規格書與推測設定，**尚未在瀏覽器實測**；若底圖空白，請改用其他底圖，並到 `js/config.js` 更換網址。
- 全程需要網路（地圖圖磚與 GAS），不做離線。
- 結案後地圖唯讀；後端也會擋下對已結案案件的區域修改。
